# Stock_Agent_Project
주식 투자를 돕는 Agent AI프로젝트입니다.

핵심 기능 
1.  CNN 기반 차트 형상 판독 
단순한 보조지표 계산을 넘어, 인간의 눈으로 차트를 분석하는 방식을 AI로 구현했습니다.

이미지 변환 파이프라인: OHLCV 시계열 데이터를 노이즈가 제거된 캔들스틱 차트 이미지로 정밀하게 변환(도해, 圖解)합니다.

패턴 자동 분류: 변환된 이미지를 CNN(합성곱 신경망) 모델에 입력하여 '헤드앤숄더', '이중 천장(더블탑)', '박스권' 등 강력한 하락/상승 징후를 나타내는 기하학적 패턴을 자동 분류합니다.

일일 스캐닝 시스템: 매일 장 마감 후 코스피 200 등 주요 종목의 데이터를 스크래핑하여 즉각적인 분석 결과를 도출합니다.

2. 실시간 AI 투자 인사이트 
토스증권 AI처럼 친절하고 예리하게, 현재 시장의 흐름을 텍스트로 풀어냅니다.

실시간 데이터 파싱: 실시간 뉴스, 공시, 그리고 장중 변동성 데이터를 지속적으로 수집합니다.

LLM 브리핑: 수집된 텍스트와 수치 데이터를 바탕으로, "지금 왜 이 종목이 오르는지", "오늘 시장의 핵심 이슈는 무엇인지"를 개인 투자자의 눈높이에 맞춰 요약 및 브리핑합니다.
